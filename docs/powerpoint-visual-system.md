# Color, typography and spacing

These are original choices for slidedesign, not McKinsey, BCG, Bain or QuantumBlack brand specifications.

| Token | Value | Use |
| --- | --- | --- |
| ink | `#17313B` | Headlines, main text |
| teal | `#187F79` | Primary chart series, emphasis |
| orange | `#C97035` | Secondary series, attention |
| muted | `#53656C` | Notes and labels |
| rule | `#CCD7D9` | Dividers and borders |
| paper | `#FFFFFF` | Background |
| wash | `#F2F6F5` | Emphasis band |

Use dark ink for small text. Accent colors are not universal small-text colors. Label data and use words alongside status colors. Never communicate an important distinction through red/green alone. Check contrast after changing tokens.

## Typography

The PowerPoint uses DejaVu Sans, an available open font family in the authoring environment. No font files are distributed or embedded. HTML and Slidev use sans-serif stacks. Receiving applications may substitute fonts; recheck wrapping after substitution.

| Role | PowerPoint size | Guidance |
| --- | ---: | --- |
| Finding headline | 26 pt | One or two lines with room |
| Section label | 10 pt | Short, uppercase, muted |
| Main text | 17 pt | Short paragraphs |
| Table text | 15 pt | Widen columns before shrinking |
| Source and footer | 9 pt | Keep legible |

The canvas is 16:9 at 1280 by 720 authoring pixels, with 64-pixel side margins and consistent title and source bands. Use 24 to 32 pixels between related blocks. Formats share named colors, with format-specific layouts.

## Public reference boundaries

[QuantumBlack's design system](https://github.com/mckinsey/quantumblack-design-system) shows reusable product UI decisions. BCG's [logo reference](https://www.bcg.com/ja-jp/bcg/logo) is linked for provenance only. Its assets are not part of this palette.
